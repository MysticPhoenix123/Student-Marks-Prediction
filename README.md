I built Student Marks Prediction to explore how a machine learning model can take information about a student and use it to estimate their marks. I used Linear Regression with Python to create the prediction model, and then built a Streamlit web app around it so that the model could be used interactively.

The project works by taking information entered by the user, processing it, and passing it through the trained regression model to generate an estimated score. I used Pandas for working with the data and Scikit-learn to build the Linear Regression model. Streamlit then helped me turn the whole process into a simple web application instead of keeping it as just a Python program.

One thing I found interesting while making this was understanding how a model can identify relationships between different variables and use them to make a prediction. It also helped me see the difference between building a model and actually making that model useful to someone. A prediction sitting inside a piece of code is very different from one that a person can interact with through a website.

While working on this project, I got hands-on experience with data preparation, regression, user input, Pandas, Scikit-learn, Streamlit, and deploying an application online. More importantly, I started to understand the full process of taking an idea, turning it into a machine learning model, and then turning that model into something people can actually use.
